# 客户与价值：01–05

用途：访谈、分群、价值主张、原因诊断与AI任务验收。来源简称见[来源与边界](provenance.md)。先选需要的动作，不按编号逐项问。

## 产品决定的八项工作表

现已取得P1第29页原始课堂工具，替代旧版仅据10月9日用户转述整理的六栏表。以下保留其八个检查维度，解释和证据状态是执行化补充，并非逐字复刻。表头另记具体产品、版本及本轮决定；一个产品一个版本，不用公司口号代替。

| 检查维度 | 直接用现有材料填什么 |
|---|---|
| 客户与情境 | 谁、什么触发事件、想完成的任务、已试过什么；进入条件与暂不服务的需要 |
| 核心收益与客户付出 | 最重要的改变；客户金钱、时间、精力和不确定性，区别于公司的交付成本 |
| 实现方式与价值主张 | 什么产品/服务动作怎样促成改变；写一版客户听得懂的承诺草案 |
| 经营取舍与交付能力 | 保留/放弃哪些内容与人群；必需投入、前置条件、能力缺口和实际可兑现范围 |
| 客户证据与替代选择 | 原话出处、最近行为、前后结果、真实比较对象；不同证据分列 |
| 关键假设与反例 | 最缺证据的因果或人群判断；不符合主张的案例，怎样解释或缩小适用范围 |
| 验证方法与判断依据 | 测谁、用什么任务/报价/体验、看什么结果；什么情况继续/修改/停止 |
| 负责人和完成时间 | 用户指定的推进人、协作交接和复查节点；未指定写建议角色/节点，不编承诺 |

每行区分“已知／推断／待验证”。未知对应具体取证动作，不让表格全是待补；填表是记录决定，不是宣告需求成立。只改文案时可引用已有完整表，增量更新相关字段，不重走全流程。

## 01 用户访谈与分群

**输入**：当前业务决定、候选客户、已购/未购/退出/成功和失败记录、真实使用经历。没有材料就直接制作本轮可用提纲。

**先听情境，再谈产品。** 核心四问来自P1第6页：在什么情况下；想完成什么；现在用什么；遇到什么障碍。必要追问：最近一次发生在何时、之前试过哪些办法、为什么选它、好在哪、哪里不足、影响了什么、后来实际怎么做、有什么记录可看。对“喜欢老师”“没时间”“想赚钱”继续追问具体经历，不诱导支持我们，也不把访谈变成推销。

**两条互补路线**：从真实情境向前找任务；从功能收益、情绪收益、社会/身份收益向后追问它何时重要、如何感知。三类是归纳视角，不要求人人三类齐全。功能“有工作流”要追问做成了什么；情绪“安心”要找到风险或不确定性减少的场景；身份“被认可”要找到谁在何种关系里如何识别，不能随意贴心理标签。

**记录与分堆**：
1. 每个受访者保留独立案例：可识别情况→触发→目标→原办法→障碍→选择→使用与变化→证据及反例。姓名可匿名，不把团队猜测改写成客户原话。
2. 跨案例按共同任务、当前进展、核心瓶颈、参与条件和期望收益分堆；人数/重复原话可记录，但小样本频次不能当总体比例。粉丝增长与已有粉丝的成交转化通常不是同一个瓶颈。
3. 为每堆给候选CVP，选择同一交付能满足的首要群体。外部入口可用1–2个容易识别的标签，实际招募再核行为和条件；人口标签与行为分群结合，不以年龄或职业单独推断需求。
4. 加入不同意、退出和未获益案例。意外买家（如无电脑或退休学员）先研究动机、条件和结果：可能是新机会，也可能是销售错配；不立即扩张当前承诺或一律排除。

**责任与节奏**：产品负责人亲自参与访谈、观察和解释；销售、教研、服务共享原始证据。可以利用课程/服务触点持续收集，说明研究用途并尊重参与意愿；不因追求大样本暂停所有行动。问卷用于验证已有假设的分布，未知需求可先定性探索。具体人数与周期由问题、差异与风险确定，不规定一人或固定人数即“验证完成”。

**产出**：已填案例卡与分群结论；或本轮招募条件、非诱导提纲、记录字段和下一次决定。仅有一句愿望时，给可检验候选，不虚构一整套画像。

**依据**：X1A 00:06–00:25、00:54–01:19；X1B 00:02–00:12；X2A 02:04–02:18、03:18–03:31；X3A 00:10–00:44；D1 00:46–00:59；P1 5–8。

## 02 从产品或客户材料形成价值主张

**输入**：实际功能、交付形式与能力、用户付出、已有客户案例。只有产品说明也能开工。

**推导**：产品事实→候选客户/情境→原办法缺口→期望收益→如何产生收益→付出和条件→兑现证据。每一步注明事实或假设；多种用途给少量有依据的候选，优先推进证据最贴近、能交付的一种。不能要求用户先交出尚未找到的CVP。

**六问**：谁；获得什么；付出什么；如何创造；凭什么能兑现；如何验证。清楚回答后填写八项表。信誉依据可以是匹配的真实案例、可体验样本、团队亲身使用成果及可查能力；名师/学校/证书只提供部分支持，不能替代客户结果。

**收益与取舍**：工具、技能、课时和工作流是机制或中间产物。往前再问一步“所以用户哪件事能做成、哪里发生变化？”收入/涨粉等远端愿望不能不经证据变为承诺；可先承诺可控制、可检验且对用户有意义的成果。并非任何业务都必须用收入结果证明价值。

**分支**：有需求没交付证据→做任务试验；能交付但用户不在乎→调整人群/收益；两者支持→形成范围明确的主张。一产品一CVP是保证需求和交付一致，不是要求每个用户人口属性相同；多产品逐个建表，不把199元课的好评移植给2980元课。

**产出**：填实八项工作表及至少一版候选：“面向【具体人群/情境】，通过【机制】，帮助你【可感知改变】，需要【关键付出/条件】，有【证据】支持。”表述自然即可；同时写清不承诺什么及哪条证据会改变设计。

**依据**：P1 3–4、8–12、23、29；X1B 00:38–01:04；X2A 00:14–00:28；X3A 00:01–00:35；X3C 00:50–01:02。

## 03 价值主张验证

四项分别判定：听得懂（不提示的复述）；在乎（具体任务与选择理由）；愿意行动（真实投入而非礼貌意向）；能兑现（成果、成本和条件）。哪项证据不足就测哪项，不自动全盘重做。

单人案例→候选CVP→更多匹配与反例→修订分群与CVP→适当问卷/行为检验。这是证据积累路径，不是固定样本量规则。一次成交只支持购买行为；本轮支持的结论限定在测过的产品、客群、价格、渠道与交付条件内。

**产出**：四项证据判断、当前版本与反例、本轮改动、下一项实验及改变决定的条件。用户已有标准用其标准；没有则提出有理由的建议，不假托课堂门槛。涉及PMF、双循环、问卷设计与加码，继续读[验证与交付](validation-delivery.md)。

**依据**：P1 26–29；X2A 00:14–00:28、02:04–02:18；X3A 00:10–00:35。

## 04 不买、不用、不续与退款诊断

**输入**：退出发生在哪步、各阶段人数/分母/周期、客户原话、前置条件、结果与参与成本。只有总转化率时先画实际路径。

| 观察 | 优先调查方向，不当作确定原因 |
|---|---|
| 没理解 | 表达、品类、示例是否清楚 |
| 理解但不重视 | 情境、问题优先级、期望收益与实际需要 |
| 在乎却未行动 | 价格、时间、设备、信任、决策权限、切换成本 |
| 购买后不参与/退款 | 流量人群、销售承诺、交接与入学条件、实际体验 |
| 参与却无结果 | 任务难度、课程机制、练习反馈、所需条件、交付容量 |
| 有结果不续 | 是否还有同类需要、频次、后续价值、竞争方案；不能直接说交付失败 |

**产出**：假设排序、各自支持/反对证据、先改哪一处及如何比较。允许明确的表达修正与调查并行；不能将所有差表现归为CVP错误，也不将销售量当唯一成功标准。

**依据**：P1 28；X1B 00:04–00:12；X2B 00:30–00:34；X3C 01:57–02:03。

## 05 AI学习交付验收

**输入**：学员实际任务、起点、允许工具与辅助、事先约定的成果要求、完成作品与成本、下一次类似任务。

**标准**：当次成果达标；下一次可独立应用；相邻任务可迁移；金钱/时间/精力可接受。“独立”可允许AI、文档等真实工作工具，但不能隐藏老师代做。分别判断“看懂／跟做／独立做／迁移”，不要用完课、满意或老师演示证明能力。

**教学动作**：讲解→讨论→实操→验证，按任务与形式安排节奏；课堂每小时循环是示例，线上也可迁移其学习逻辑，不机械照搬时长。先准备学员材料、设备/账号与练习任务，再设计反馈和课后行动检查。课程、可复用方法/skill与agent可以组合，是否开发由客户任务与成本决定，不自动立项。

**产出**：填实的任务验收表（起点、作品、质量要求、辅助程度、耗时、判断）；一段能执行的教学/练习安排；未达标的补练与下一任务观察。当前作品合格但下次未测，就写“当次支持，迁移待验证”。线上/线下分别测试条件和结果；PPT中的星途效果仍是待检验假设。

**依据**：P1 19、24、27；X1A 01:13–01:17；X1B 01:57–02:05；X2A 00:11–00:13；X3A 00:01–00:09；X3C 01:15–01:29。
