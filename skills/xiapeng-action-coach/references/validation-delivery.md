# 验证与交付：从发现需求到可重复结果

用于PMF、课程研发、问卷、满意度、已售交付与跨产品迁移。动作01–05的详细表格见[客户与价值](customer-value.md)。本文件是对星途多处发言的流程整合，阶段名称与记录格式不是新增公司制度。

## 一、两条相互校正的验证循环

**获客循环**：候选CVP→明确目标人群→真实触达→理解/在乎/行动→定位退出→修订CVP与表达。销售话术、账号介绍、内容、直播和产品页面承接同一价值；不同账号可以有不同目标，不要求全公司一套口号。

**交付循环**：已承诺CVP→确认起点/条件→设计关键体验→实际任务与成果→客户体验及推荐反馈→补救/改版→再次验证。好卖不证明做得到，满意不证明学会，结果达成也不证明获客成本可持续。两条循环共享证据、分别验收，不让销售、教研与班主任互相推责。

PMF指产品与市场匹配。本批星途原记录明确讨论PMF，旧版“PMI未定义”不再作为当前流程概念；不据此断言旧记录每处PMI都是同一词。一次研究只能补充匹配证据，不能宣布完整PMF已通过。

## 二、阶段与推进门槛

| 状态 | 这一轮交付 | 下一阶段所需证据 |
|---|---|---|
| 只有想法/功能 | 候选情境、收益假设、最小访谈/观察 | 有具体任务、替代选择与反例，能辨识候选群体 |
| 有案例、适用面未知 | 个案CVP和跨案例分群，修订主张 | 不同案例支持共同需要，边界清楚；不能凭一人外推 |
| 需求有支持、行为/交付未定 | 有范围的报价、体验或任务试验 | 理解、在乎、行动、兑现分别有证据，成本可记录 |
| 有局部重复结果 | 跨批次/跨执行者检查与容量核算 | 结果在规定条件下重复，交付与现金资源支持扩大 |
| 已售产品出现问题 | 当期补救方案及下一期设计分别输出 | 已售承诺处理妥当；新版再独立验证 |

事先记录试验对象、产品版本、渠道、承诺/报价、真实交付、投入上限、观察周期、预期证据、继续/修改/停止条件、推进人及交接。按最危险未知设计最小试验，不默认每次必须小到不足以产生证据。14天、“再试两次”、某分数都是情境示例；标准由业务条件和失败代价决定。

快速开始允许使用带假设的草案；扩大宣传或投入之前严格检查。明确反证出现时修改或停止原假设，不用无限迭代掩盖没有进展。涉及已售学员时，停止新招募与履行已有承诺是两个决定。

依据：X1B 00:25–01:09、01:49–01:57；X2A 00:14–00:28；X3A 00:10–00:35；P1 26–29、P2 28–29。

## 三、问卷与评分不能混用

先明确定义再用数据：

| 指标/证据 | 能支持什么 | 不能替代什么 |
|---|---|---|
| 情境访谈与真实经历 | 理解动机、任务、障碍与假设 | 总体需求比例、未来成交保证 |
| 需求问卷 | 在给定样本与题目下的选择分布 | 代表性未经说明的全市场结论 |
| 任务前后自评分 | 学员主观感知变化 | 客观成果、NPS、因果证明 |
| 作品/下一任务 | 实际能力与迁移范围 | 自动证明满意、推荐或持续购买 |
| 满意度 | 对此次体验/承诺的评价 | 忠诚、PMF、复购 |
| 推荐意愿与NPS | 对推荐问题的回答及群体汇总 | 每位高分客户必然购买、LTV保证 |
| 复购/转介绍行为 | 已发生的后续选择 | 无限外推未来收益，或假定来自某一个触点 |

**NPS校准（外部定义核验）**：先问0–10分推荐可能性。推荐者9–10，消极者7–8，贬损者0–6；NPS＝推荐者比例－贬损者比例，范围−100至100。分母为有效回答者总数；记录样本、回收率、时间和触点，不把缺答计零。一人打9分是推荐意愿回答，不是“群体NPS为9”。问“课程满意吗”或“任务能力几分”得到的分数不是NPS。

低评分追问具体事件、期待与落差；高评分也查是否产生成果、还有何种需要。调查应避免诱导/施压打分。改善触点后持续观察，同期变化只能先视作线索，非因果证实。评分、作品和行为交叉看，不用单一指标统治交付。

来源：X2A 01:08–01:16、02:04–02:18；X3A 00:10–00:35（约00:33明确任务自评分不是NPS）；[Bain测量说明](https://www.netpromotersystem.com/about/measuring-your-net-promoter-score/)（2026-10-19核验）。

## 四、课程与销售交接

研发同时写：适合谁、谁目前不适合、必要工具/时间/基础、具体可交付改变、客户需要做什么、我们如何帮助、遇阻如何补救。销售端用条件与期望校准，不能为了GMV主动招入明显无法兑现的需要。

交付节点围绕“用户已得到什么”设计：入学起点→第一次可感知价值→练习与反馈→结课成果→下次独立使用。第一天/第一周是可选观察节点；上课签到和发放资料只是过程指标。

对已经购买但不匹配者，先核查真实承诺、现有条件、所缺支持与可行补救，与用户决定沟通方案；不擅自拒绝服务、改合同或许诺退款。下一期可以修改招募范围、内容、期限、形式或价格。若21天不足以实现目标，就审视目标可控性、训练周期和反馈投入，不随意把目标降到“知道工具”后声称完成原承诺，也不把更长时长当效果保证。

线上可验证某种需求/内容信号，但无法替代线下的强度、差旅、价格、现场辅导与收益检验。低价产品必须有独立客户价值；转正价需新需求、适配、承担能力和交付证据，不能默认所有老客都应升级。

依据：X1A 00:38–00:53；X1B 00:04–00:12、00:38–01:04；X2A 02:46–02:59；X2B 00:30–00:34；X3A 00:01–00:09；X3C 00:50–01:02、01:15–01:29。

## 五、本轮应交付的东西

按请求直接给已填实的试验卡、课程安排/任务验收、问卷题目与统计口径、当期补救与下一期修改。至少写清当前支持的局部结论、最关键缺证据、可执行动作和下一次决定。用户要问卷时先给实际题目和选项，不仅说“去调研”；用户要课程时写可实施教学片段，不只列教学原则。
