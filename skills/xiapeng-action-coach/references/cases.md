# 案例迁移：保留选择的难度

案例用于练习判断，不是当前市场数据，也不是普遍成功保证。资料为用户提供的非官方中文译本；以下为摘要和迁移方法，不复制全文。原文页与PDF页可能不同，此处统一PDF页。

## Chewy：服务承诺如何改变经营选择

**资料范围**：《Chewy案例_全文中文译本.pdf》，27页；案例决策时点2013年12月，原文修订2019-09-17。

客户价值不是“卖宠物食品”或单纯便宜，而是将熟悉宠物、有人倾听的服务与可靠及时的补货结合。手写卡片和油画是具体情境下的关系行动，不是所有企业必须抄的服务项目（PDF8–9）。初期聚焦东海岸与一至两天送达承诺相关，说明客户价值会限制服务范围（9–10）。

履约瓶颈关系到承诺兑现，但方案不止“自建或不建”：继续现有3PL并调整增长、引入其他3PL、混合试点、全面自营。PDF12–14同时列出资本、专业能力、过渡期、库存、人才与现金风险。自营履约中心不能泛化成自建全部末端运输；课堂提及的后续收购不属于本案结尾的决策证据，不拿未核实历史补成答案。

**可迁移问题**：用户不能丢失的结果是什么？现在在哪个环节失守？哪些能力必须控制，哪些可合作？四类方案的能力、现金、速度与过渡风险如何？先做什么能够降低未知？

**反例约束**：有价值的服务可能值得更多投入，但不能推出任何服务成本都合理、信任必然变利润或自营总比外包好。案例停在待决策状态，不把后来成功倒灌成当时必然正确。

## FIGS：围绕同一客户价值选择增长路径

**资料范围**：《FIGS_打破医护服装行业的现状_全文中文译本.pdf》，31页；案例时点2023年10月，发布日期2024-02-01。

功能、舒适、购买便利与医护身份认同相互支持；创始人亲自观察工作与顾客反馈，是产品细节的来源，不是凭空加功能（PDF3–5）。DTC提供直接反馈关系，同时带来渠道与能力取舍。早期少量款式说明专注，不证明任何业务都应固定SKU数量。

三项机会各有新增价值与新约束（PDF9–13）：

| 路径 | 要验证的新增价值 | 重要成本/风险 |
|---|---|---|
| 国际市场 | 新地区实际需要、可触达和可接受价格 | 本地化、履约、库存、监管与利润；历史法规不能照搬当前 |
| TEAMS机构采购 | 团队采购任务、决策和支付条件 | 定制、折扣、销售周期、技术支持和账期 |
| 社群中心/实体门店 | 试穿、即时拿货、关系与新客触达 | 选址、固定投入、人员、库存、渠道分流 |

原案有小型专属团队与共享资源安排，但最终仍问如何排序、能否同时推进；不是“已经证明三线全投最好”。多渠道消费者较高消费也不自动证明开店的因果收益。

**可迁移产出**：沿客户价值、真实增量、复用优势、能力缺口、资源需求、关键未知、第一项实验做候选比较；选出当前优先验证方向。用课堂增长提案，不照抄FIGS收入、NPS或行业规模作为自己门槛。
